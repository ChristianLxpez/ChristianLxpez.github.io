Mechanics

How it works.

01
User describes a business process
The terminal prompts the user to describe any workflow — invoicing, customer support, inventory, HR processes. Free text, no structured form required.
02
Structured prompt sent to Gemini 2.5 Flash
A system prompt instructs the model to act as a digital transformation consultant and return only valid JSON — no markdown, no freetext.
03
JSON parsed and rendered as a formatted report
The raw JSON is deserialized and displayed using ANSI color codes — with sections for each automation opportunity, quick wins, complexity and ROI.
04
Output saved to resultado_analisis.json
The structured analysis is persisted to a JSON file — ready to be consumed by other tools, dashboards or further automation pipelines.

Features

What it includes.

🔑
Secure API key management
API key loaded from .env via python-dotenv. Never hardcoded, never committed to Git.
🤖
Gemini 2.5 Flash
Uses Google's latest free-tier model. 1,500 requests/day at zero cost — no credit card needed.
📐
Structured JSON output
Forces the LLM to return strict JSON. Handles markdown fences and parses safely with error handling.
🎨
ANSI terminal formatting
Clean visual hierarchy with gold headers, cyan labels and green highlights. Readable on any terminal.
💡
Business-focused analysis
Returns automation opportunities, recommended tools, ROI estimations and a quick win for each process.
📁
JSON export
Every analysis is saved locally as resultado_analisis.json for further use or integration.

Setup

Run it yourself.

Get a free API key at aistudio.google.com — no credit card needed. Then:

Install dependencies

pip install google-genai python-dotenv

Configure your API key

# Create a .env file:
GEMINI_API_KEY=your_key_here

Run the analyzer

python business_process_analyzer.py

requirements.txt

google-genai>=1.0.0
python-dotenv>=1.0.0
